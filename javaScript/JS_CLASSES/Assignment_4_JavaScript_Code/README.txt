ASSIGNMENT 4 - JAVASCRIPT CODE

There is one .js file for each question (q1.js through q9.js).

Run console-only questions with Node.js:
  node q1.js
  node q3.js
  node q6.js
  node q9.js

Q2, Q4, Q5, Q7, and Q8 use browser DOM forms. To run them:
1. Open the relevant .js file in VS Code.
2. Create a simple HTML file with a script tag pointing to that JS file, or paste the code into the browser console.
3. Open the HTML file in a browser and interact with the form.

All files use core JavaScript (ES6+) and include comments. Form questions use DOM APIs and console.log().
