JavaScript Assignment 1
=======================

Contains one separate JavaScript file for each of the 10 questions.

How to run:
1. Extract this ZIP file.
2. Open a terminal in the extracted folder.
3. Run any file using Node.js, for example:
   node Q1_Personalized_Login_Greeting.js

Alternatively, open a .js file in your editor and run it in the browser console.

Notes:
- Change the sample values (name, marks, expenses, temperature, etc.) to test other cases.
- Q7 uses a random secret number; change userGuess to test different guesses.
- Q9 generates a random arithmetic question and prints its correct answer.
